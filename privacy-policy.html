Privacy Policy — YOUTUBE UPLOADER AGENT (JARVIS)

Last updated: October 22, 2026

YOUTUBE UPLOADER AGENT (JARVIS) is a private, single-operator tool owned and operated by Joshua McCullough ("the operator"). It is used solely to upload and manage videos on the operator's own YouTube channels. It is not a public service and is not offered to third-party users.

What the tool accesses

With the operator's own Google authorization (OAuth), the tool accesses the YouTube Data API to upload videos, set titles, descriptions, and thumbnails, and read back basic channel and video information for the operator's own channels. It accesses no other Google services and no data belonging to anyone other than the operator.

What data is stored

The tool stores the operator's own OAuth access and refresh tokens on the operator's own computer so uploads can run unattended. No personal data of viewers, subscribers, or any third party is collected, stored, or processed.

How data is used and shared

Data accessed through Google APIs is used only to perform the uploads and channel-management actions the operator directs. It is never sold, rented, shared with third parties, used for advertising, or used to train models. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Data retention and deletion

OAuth tokens are kept only while the operator uses the tool and can be revoked at any time from the operator's Google account permissions page, which immediately ends the tool's access. Locally stored tokens are deleted when the tool is retired.
